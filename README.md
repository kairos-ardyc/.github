# Kairos — Сервис видеоконференций

**Kairos** — это модульный сервис для проведения видеоконференций, организованный по микросервисной архитектуре. Сервис доступен по адресу: [https://kairos-test.ardyc.ru](https://kairos-test.ardyc.ru)

## 🔧 Архитектура

Сервис состоит из 4 микросервисов:

1. **Auth Service (Авторизация)**
   - Обеспечивает регистрацию, аутентификацию и управление сессиями пользователей.
   - Поддержка JWT, OAuth (если применимо).
   - Защита доступа ко всем остальным микросервисам.

2. **Meeting Service (Собрания)**
   - Управление событиями/встречами: создание, редактирование, удаление.
   - Приглашения участников, настройки расписания.
   - Сопровождается базой данных собраний.

3. **Video Service (Видеоконференция)**
   - Реализует потоковую передачу видео и аудио.
   - Взаимодействие через WebRTC или аналогичный протокол.
   - Поддержка комнат, включения/отключения камеры, экрана, чата и т.д.

4. **Notification Service (Уведомления)**
   - Рассылка email или push-уведомлений участникам.
   - Интеграция с собраниями и событиями.
   - Планирование и повтор уведомлений (напоминания).

## 🚀 Развёртывание

- Node.js / Java / Kotlin
- PostgreSQL
